# 各项目说明的「通用三条」

**为什么要这个**：「连着电脑」的聊天会话不一定会自动带上 Space 根目录的 `CLAUDE.md`。AI 项目里每个会话一定会带上的，只有项目自己的说明文字。所以三条通用规则要写在每个项目说明的最前面。

**怎么用**：在你的 AI 客户端里打开每个项目，把下面整段贴到项目说明最前面（原有内容保留在后面）。每个项目贴同一段。

```
【通用三条，放最前面】
1. 开工先读 Space 根目录的 CLAUDE.md（里面的「基础卡」有设备、订阅、助理、连接方法；有的会话不会自动带上，必须主动读），再读本项目 README 的「当前状态」。读到基础卡的校验暗号才算读到了。
2. 我问「做完没」「某某任务怎么样了」：先去任务单或本项目 STATE 里查，回答时带上更新时间；查不到就说「没有记录」，不凭印象答。
3. 我拍板的事当场写进本项目 README「当前状态」（或对应模块 STATE），过程另存带日期的记录；收工前再对一遍这次会话里我定的事有没有都写进去。
```

**验收**（贴完做一次）：在该项目新开会话，①问「基础卡暗号是什么」要答对；②拿一个真实任务问，要答出状态和更新时间；③拿一个不存在的任务问，要答「没有记录」。

## 新建、停掉项目
- **新建**：建文件夹和带「## 当前状态」的 README，在 AGENTS.md「模块写入方表」（或 `.space/config.json` 的 modules）登记，在 AI 客户端新建项目、把通用三条放在项目说明最前面，然后做上面的验收。
- **停用**：把 README「当前状态」改成退役（写日期和原因），在 AGENTS.md 标已退役，资料默认保留；要清文件就用 `{{py}} .space/recycle.py`（{{keep_days}} 天内能捞回）。永久删除要先问主人。
