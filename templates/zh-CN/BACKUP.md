# 异地备份

状态：{{backup_status}}（只有你亲手从备份里恢复出一个文件之后，才把 `.space/config.json` 里的 `backup.status` 改成 `done`）。

放在同一块硬盘、同一个同步服务里的备份，不算异地备份。至少选一个「丢了这台电脑也还在」的地方：

| 办法 | 适合 | 说明 |
|---|---|---|
| 放在另一个地方的外接硬盘 | 所有人 | 隔一阵子把 Space 文件夹复制过去，标上日期 |
| 另一个云盘或同步账号（不是 Space 所在的那个） | 有同步盘的人 | 同步不等于备份：删除也会同步，所以要留带日期的副本 |
| 私有远端的 `git` 仓库 | 熟悉 git 的人 | 不要推送密码和密钥；保持私有 |
| 云服务器快照 | 有服务器的人 | 确认快照真的能恢复 |

## 怎么验证（做一次）
1. 做一次备份。
2. 从备份里恢复一个文件到临时文件夹。
3. 打开它，跟原件对一下。
4. 对上了，再把 `backup.status` 改成 `done`，在 `backup.method` 写上办法和日期。
